# Awesome AI Games (Just the Classics)

This is a list of classic fun games that you can play in the browser.

## The List

### Featured

* [Hop.Earth](https://hop.earth/) - Inspired by Need for Speed × Google Maps (open-world driving / drop-in). Three.js/WebGL; real OSM roads + terrain; parachute drop; call a car; multiplayer races; night mode WIP. Viral on X.
* [Vesperfall](https://vesperfall.mengto.chatgpt.site) - Inspired by Diablo-style isometric action RPGs. Three.js; camera controls; VFX; audio; monsters; combat systems; open-source assets/skills. [Tweet](https://x.com/MengTo/status/2080915786206789733)
* [Claude of Duty: Vibe Slops II](https://vibeslops.luckeysystems.com/) - Inspired by Call of Duty: Black Ops II. Three.js FPS; BO2 map export; gunplay; multiplayer-style room/menu flow. [Tweet](https://x.com/threejs/status/2096829728170897425)
* [APEX / Coast Run](https://apex-coast-run.mindblown.ai) - Inspired by Need for Speed. Three.js coastal arcade racer; mobile and desktop performance modes. [Tweet](https://x.com/mindblown_ai/status/2097053892152594854)
* [Modern Claudefare](https://www.modernclaudefare.com/) - Inspired by Call of Duty / Modern Warfare multiplayer (Rust, Nuketown, Highrise, Terminal vibes). Three.js; bots + up to 4-player MP with voice; TDM/FFA; many procedural weapons; controller support; desktop-oriented.

### Racing

* [Velocity GP](https://www.velocity-gp.com/) - Inspired by WipEout. Three.js anti-gravity racer; AI opponents; missiles; daily circuit; friend ghosts; GPU quality detection.
* [HexGL](http://hexgl.bkcore.com/play/) - Inspired by WipEout / F-Zero. Classic Three.js WebGL time-trial; Mobile/Mainstream/Ultra presets; long-running Chrome Experiments / FWA favorite.

### Shooters & open world

* [Claude of Duty](https://ericspencer.us/Claude-of-Duty/) - Inspired by modern Call of Duty FPS. Distinct from Vibe Slops II. Three.js + WebGL2; fully procedural art/audio; ADS/lean/AI enemies; [open source](https://github.com/mshumer/Claude-of-Duty).
* [Below the Grassland](https://below-the-grassland.ameen-abdullah.dev) - Inspired by GTA-style open-world presentation. Three.js + WebGPU; cinematic camera; player switching; visual presets; graphics settings; immersive audio. [Tweet](https://x.com/ameengl/status/2094787364946403478)
